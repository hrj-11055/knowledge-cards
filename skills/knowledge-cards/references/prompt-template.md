# Image prompt template

```text
Create one [aspect ratio] study card for [audience] in [style].
Title, exact text: [title]
Body, exact text: [short, verified lines]
Visual: [specific diagram or illustration, with labels and directions]
Layout: [text and visual placement, safe margins]
Palette: [colors or HEX values]
Keep all text legible. Do not add facts, labels, or formulas not supplied above.
```

Keep the source ledger outside the picture unless attribution is required on the card. A request for exact text does not guarantee exact rendering; compare the resulting pixels with the ledger.
