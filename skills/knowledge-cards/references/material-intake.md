# Electronic material intake

Record before drafting cards:

| Field | Record |
| --- | --- |
| File name and format | PDF / DOCX / MD / TXT / image / other |
| Owner or source | Author, organization, and user's relationship to the file if known |
| Scope | Chapters, pages, audience, requested card count |
| Readability | Text extracted, visual reading or OCR needed, unreadable pages |
| Coverage | Table of contents compared with extracted material; missing sections |
| Rights and sharing | Private study, classroom use, or public distribution; any known restrictions |

For each card, cite the exact page, heading, or paragraph in the intake ledger. Check formulas against the page image even when text extraction succeeds. For diagrams, redraw only when the relationship is understood and reuse rights allow the intended output. A missing or ambiguous source segment remains `needs_source` until resolved.
